# Atlas de projetos — Anderson

Campus interativo em Next.js e Three.js para acompanhamento de cinco frentes de trabalho. Interface somente leitura; conteúdo mantido em content/painel.json.

## Desenvolvimento

npm ci
npm run dev

## Publicação

GitHub Actions publica no GitHub Pages a cada push na branch master. Em Settings > Pages, selecione GitHub Actions como origem. O workflow publica somente a exportação em out/.

O mapa e seus personagens e veículos são ilustrativos.
